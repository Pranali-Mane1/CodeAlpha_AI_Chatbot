# AI Chatbot Using Java

A rule-based chatbot developed using Java Swing as part of my CodeAlpha Java Programming Internship.

## Features

- Graphical user interface using Java Swing.
- Interactive chat window.
- Send button and Enter key support.
- Predefined responses for greetings and common questions.
- Responses about Java and Artificial Intelligence.
- Handles unknown questions with a fallback response.

## Technologies Used

- Java
- Java Swing
- AWT
- Object-Oriented Programming
- Basic text processing and rule-based logic

## How to Run

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

```bash
javac AIChatbot.java
java AIChatbot
```

## How It Works

The chatbot converts user messages to lowercase and checks them against predefined keyword rules. It then displays the corresponding response in the graphical chat window.

**Note:** This is a rule-based chatbot. It does not use a trained machine-learning model or an external AI API.
